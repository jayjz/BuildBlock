# Roadmap

P0 is a public, evidence-backed district with stable blocks and temporary recent activity state. It deliberately excludes ownership, history, multiplayer, authentication, rankings, and AI.

The next gate is qualitative: visitors should recognize a block, explain its visible state through evidence, and want their own place. Only after that should BuildBlock evaluate claimed identity and durable history; collaboration needs verified attribution before it becomes a world rule. Agents are a later inhabitant, never a P0 foundation.
