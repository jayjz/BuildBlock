# Roadmap

BuildBlock development is organized as gated product phases.

See [`docs/PHASES.md`](./PHASES.md) for the canonical phase sequence and acceptance criteria.

## Current state

P0 is a public, evidence-backed district with stable workshops and temporary repository-fronted observed-work state.

The implementation deliberately excludes ownership, history, multiplayer, authentication, rankings, and production AI.

The current product gate is qualitative validation:

- visitors should recognize a block;
- visitors should explain visible state through evidence;
- developers should demonstrate credible desire for a block of their own.

Only after that gate should BuildBlock advance to claimed identity and durable history.

Collaboration requires verified attribution before becoming a world rule.

Agents are a later inhabitant, never a P0 foundation. `EXP-AGENT-001` is an isolated architecture experiment and does not advance the production phase.
