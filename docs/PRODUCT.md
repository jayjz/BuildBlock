# BuildBlock P0

BuildBlock is a persistent developer world where real software work changes a recognizable place. P0 tests whether an evidence-backed public GitHub view makes a developer want a block.

District 01 is a crafted miniature district, not a ranking or analytics dashboard. A block has a permanent address and architectural identity. Recent observed work temporarily lights its facade and may add a merge pennant or release beacon. Curated public profiles do not imply participation or endorsement.

The public event feed is incomplete. BuildBlock therefore says “observed public activity,” never “all activity,” “productivity,” or “inactive.”
