# BuildBlock P0

BuildBlock is a persistent developer world where real software work changes a recognizable place. P0 tests whether an evidence-backed public GitHub view makes a developer want a block.

District 01 is a crafted miniature district, not a ranking or analytics dashboard. A block is a permanent workshop with a fixed address and architectural identity. Its frontage shows up to three repositories recently observed in the current window; bounded merge and release states appear with the relevant repository work bay. Curated public profiles do not imply participation or endorsement.

The public event feed is incomplete. BuildBlock therefore says “recently observed here” and “No public work observed in this window,” never “all activity,” “productivity,” or “inactive.”
